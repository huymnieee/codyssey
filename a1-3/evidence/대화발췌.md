# Codex 실제 대화 발췌

2026-10-15 이 과제를 진행한 Codex 대화에서 **실제 오간 문장 일부만** 순서대로 발췌했습니다. 전체 원본 내보내기가 아니며, 발췌 사이의 도구 실행과 나머지 대화는 생략했습니다. 기술 검증 기록은 `검증기록.md`에 따로 있습니다.

## 사용자 요청 일부

> 학원과제이고 나는 ai 초보야
> 어려운 용어, 문장 쉽게 설명해주고 뭐하라는건지 쉽게 설명해줘
> 그리고 내가 해야될것 알려줘
> 크게 틀 잡아서 뭐뭐해야되는지 등

## Codex 답변 발췌 1: 과제 파악

> 과제의 핵심은 **“AI 기능이 있는 작은 웹사이트를 만들고, 인터넷 주소로 공개하기”**예요. 제출물은 ① 웹사이트 주소 ② GitHub 코드 ③ 설명서 ④ 서비스 기획서 ⑤ 화면과 AI 사용 과정 증빙입니다.

## Codex 답변 발췌 2: 구현 범위

> 사이트는 **소개 → AI 학습 도우미 → 사용 방법 → 자주 묻는 질문**으로 구성할게요. 코드뿐 아니라 기획서, 쉬운 용어 설명, 발표용 설명과 제출 체크리스트도 함께 만들겠습니다.

## Codex 답변 발췌 3: 화면 구현

> 사이트 화면과 질문 입력 기능을 만들었습니다. 예제 질문을 누르고 설명 수준을 고르면, AI가 **한 줄 요약·쉬운 설명·비유·퀴즈**를 만들어 주는 구조예요. 결과를 학습 노트로 내려받는 기능도 넣었습니다.

## Codex 답변 발췌 4: 오류 발견

> 컴퓨터와 휴대폰 크기에서 화면이 잘 표시되고, 빈 질문 안내도 확인했습니다. 입력 검사와 API 오류 처리 자동 점검 8개도 통과했어요.
>
> 다만 실제 AI 호출에서 연결 오류가 나와 원인을 확인 중입니다. 실제 답변이 나오는 것까지 확인한 뒤 증빙으로 남기겠습니다.

## Codex 답변 발췌 5: 실제 동작 확인

> 실제 Gemini 연결이 성공했고, 휴대폰 화면에서도 질문 → 설명 → 퀴즈까지 동작하는 것을 확인했습니다. 처음 연결 오류 뒤 재시도에서 정상 응답을 받았습니다.

## 이 발췌가 보여주는 것

과제 요구를 설명 → 서비스 기능 설계 → 코드 작성 → 오류 발견 → 재시도 및 검증이라는 AI 코딩 도구 사용 과정을 보여줍니다. 수강생이 직접 코드를 작성했다거나 직접 테스트했다고 주장하는 자료가 아닙니다.
