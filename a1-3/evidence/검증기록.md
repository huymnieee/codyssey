# 검증 기록 · 2026-10-15 (한국 시간)

**로컬에서 실제 AI 연결과 화면 확인 완료. Vercel 공개 배포는 미완료입니다.**

로컬 주소 `http://127.0.0.1:8003`은 공개 배포 주소가 아닙니다. 아래 이미지는 로컬 검증 증빙이며, 공개된 Vercel 환경에서의 증빙을 대신하지 않습니다.

## 확인한 것

| 점검 | 결과와 범위 |
| --- | --- |
| 자동 테스트 | `python3 -m unittest discover -s tests -v`: 8개 통과. 입력 길이/수준/키 누락/401·403·429·500/시간 초과/네트워크/응답 형식/비밀 값 제거를 모의 응답으로 검증 |
| JavaScript 문법 | `node --check js/app.js` 통과 |
| 실제 AI 호출 | Gemini `gemini-3.1-flash-lite` 실제 응답 확인. API를 묻는 일반 질문과 300자 긴 질문 성공 |
| 실제 결과 저장 | `live-api-result.json`: HTTP 200, `mode=live`, `source=gemini`, 입력 300자, 결과 제목 ‘웹사이트를 만드는 네 가지 친구들’ |
| 실제 브라우저 흐름 | 예제 질문 클릭 → 버튼 잠금/로딩 → AI 설명 → 퀴즈 정답 펼치기 확인 |
| 빈 입력 | 브라우저 안내 확인. 서버에도 직접 빈 질문/잘못된 JSON을 보내 각각 HTTP 400 확인 |
| 로컬 경로 | `/` 200, `/.env` 404, `/dev_server.py` 404, GET `/api/learn` 405 |
| 화면 크기 | 데스크톱 1440×1000, 태블릿 768×1024, 모바일 390×844 설정에서 화면 확인. 모바일 가로 넘침 없음 |
| 메뉴 | 소개/AI 학습 메뉴의 해당 구역 이동과 네 구역 존재 확인 |
| 다운로드 | 기능 구현. 자동 브라우저의 다운로드 완료 이벤트가 시간 초과되어 파일 저장 완료는 미확인 |

첫 실제 API 요청은 제공자 연결 오류로 502 안내를 반환했습니다. 이후 수동 재시도와 브라우저 실행, 긴 질문 실행은 성공했습니다. 실패를 성공으로 바꾸는 고정 답변이나 데모 대체는 사용하지 않았습니다.
