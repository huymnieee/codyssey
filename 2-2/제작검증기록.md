## 두 AI 비교

- AI A 서비스: Codyssey 학습 네이토
- AI A 모델 이름: GPT-5.5
- AI B 서비스: Codyssey 학습 네이토
- AI B 모델 이름: Gemini 3.1 Pro

### 동일한 기획서와 함께 전달한 요청

두 AI의 새 대화에 아래 요청문을 보내고, 그 뒤에 2-1에서 작성한 식사비 계산기 기획서 전체 내용을 그대로 붙여넣었다. 두 AI에 같은 기획서와 같은 제작 조건을 전달했다.

> 아래 기획서를 바탕으로 식사비 계산기 웹페이지를 만들어 주세요.
>
> 제작 조건:
> 1. 기획서의 필수 기능과 완료 기준을 반영해 주세요.
> 2. HTML, CSS, JavaScript를 HTML 파일 하나에 모두 포함해 주세요.
> 3. 다른 파일, 외부 자료, 회원가입, 로그인, API 키, 별도 서버 없이 브라우저에서 열어 사용할 수 있게 만들어 주세요.
> 4. 휴대전화에서도 사용할 수 있게 만들어 주세요.
> 5. 기획서의 추가 기능인 ‘다시 입력하기’ 버튼은 이번에는 구현하지 마세요.
> 6. 저장해서 바로 열 수 있는 전체 HTML 코드를 하나의 코드 블록으로 제공해 주세요.
>
> 아래는 두 AI에 동일하게 전달하는 기획서 전문입니다.

위 문장 뒤에 붙여넣은 기획서는 평가 참고 자료인 기획서.md로 함께 제출한다.

### 두 결과의 비교

두 AI가 만든 HTML 파일을 각각 저장하고 브라우저에서 열어 같은 방법으로 확인했다.

| --- | --- | --- |
| 전체 식사비 30,000원, 인원수 3명을 입력하고 계산하기 | 한 사람당 10,000원, 남는 금액 0원이 표시됐다. | 한 사람당 10,000원, 남는 금액 0원이 표시됐다. |

| 계산 결과가 표시된 상태에서 전체 식사비만 지우고, 인원수는 3명으로 둔 채 계산하기 | ‘식사비와 인원수를 입력해 주세요’라는 안내가 나오고 이전 계산 금액이 사라졌다. | ‘식사비와 인원수를 입력해 주세요’라는 안내가 나오고 이전 계산 금액이 사라졌다. |

위 세 가지 확인에서는 두 계산기 모두 예상한 결과가 나왔다.

### 선택한 결과물과 근거

- 선택한 결과물: GPT-5.5가 만든 식사비 계산기
- 선택한 HTML 파일 이름: 식사비계산기_GPT_v1.html
- 직접 작성한 선택 근거: “GPT 계산기가 결과가 더 보기 편해서 GPT로 할게.”

선택하지 않은 Gemini 계산기의 결과는 위 비교표에 설명으로 남겼다. 제출할 HTML은 선택한 GPT 계산기 파일 1개다.
