# Vercel 배포: 필요한 계정 작업만

먼저 README에서 최신 배포 상태를 확인하세요. 이미 배포되었다면 새 프로젝트를 만들 필요가 없습니다.

## Codex에 Vercel을 연결할 수 있다면

Vercel 연결을 완료하고 이 채팅에 알려 주세요. 연결 후 제공되는 기능으로 배포·환경 변수 설정·공개 접속 확인을 이어서 할 수 있는지 확인합니다. 연결 버튼을 눌렀다는 사실만으로 배포가 끝나는 것은 아닙니다.

## 직접 설정해야 한다면

1. [Vercel](https://vercel.com/new)에 로그인합니다. GitHub 계정으로 연결할 수 있습니다. 계정 가입의 동의 화면은 직접 확인합니다.
2. **Import Git Repository**에서 `huymnieee/codyssey`를 고릅니다. 목록에 없으면 GitHub 연결에서 이 저장소 접근을 허용합니다.
3. 프로젝트 이름은 `gongbu-hanip`처럼 입력합니다. 이미 사용 중인 이름이면 다른 이름을 고릅니다.
4. **Framework Preset: Other**로 설정합니다. 이 과제는 React 프로젝트가 아닙니다.
5. **Root Directory: `a1-3`**를 선택합니다. 저장소 전체 중 이번 과제 폴더만 배포하는 중요한 설정입니다.
6. Build Command/Output Directory는 기본값을 유지합니다. 별도의 npm 설치나 빌드가 필요 없습니다.
7. **Environment Variables**에 아래 두 항목을 넣습니다. Production 환경에 적용되는지 확인합니다.

| 이름(Name) | 값(Value) |
| --- | --- |
| `GEMINI_API_KEY` | 본인 Gemini API 키. 채팅·코드·스크린샷에는 쓰지 않습니다. |
| `GEMINI_MODEL` | `gemini-3.1-flash-lite` (현재 로컬 검증에 사용한 모델) |

8. **Deploy**를 누릅니다. 키를 배포 후에 추가/수정했다면 **Redeploy**도 실행합니다.
9. 나온 `https://…vercel.app` 주소에서 API 예제 질문을 눌러 실제 설명이 나오는지 확인합니다. 다른 사람이 로그인 없이 열 수 있는지도 확인합니다.
10. 주소를 Codex에게 알려 주세요. README의 배포 주소, 공개 배포 검증과 증빙을 갱신합니다.

## 이 컴퓨터에 저장된 키를 내가 복사하기

Finder에서 `a1-3` 폴더를 열고 `Command + Shift + .`를 누르면 숨김 파일 `.env`가 보입니다. 편집기로 열어 `GEMINI_API_KEY=` 뒤의 값만 복사해 Vercel의 Value 칸에 붙입니다. 보관된 다른 키를 업로드할 필요는 없습니다. 이 파일을 GitHub에 끌어다 놓지 마세요.

키를 새로 만들어야 한다면 [Google AI Studio](https://aistudio.google.com/app/apikey)에서 본인 계정으로 발급합니다. 이용 가능 모델과 계정의 비용·할당량은 해당 화면에서 확인합니다.

## 배포 뒤 문제가 있으면

| 증상 | 확인 |
| --- | --- |
| 첫 화면 404 | Root Directory가 `a1-3`인지 확인 |
| API 404 | `api/learn.py`가 올라갔는지, Framework가 Other인지 확인 |
| AI 연결 설정이 아직… | Production 환경 변수의 이름/값, 변경 뒤 재배포 확인 |
| 인증 설정 확인… | Gemini 키 권한/유효성 확인 |
| 이용 한도에 도달… | Gemini 계정의 요청 한도/쿼터 확인 후 재시도 |
| 로컬에서는 되는데 공개 주소에서는 실패 | Vercel 로그의 상태 코드와 환경 변수 확인. 키나 인증 헤더가 나온 화면은 공유하지 않음 |

코드를 수정해 GitHub에 저장하면 연결된 Vercel이 다시 배포합니다. 새 배포가 성공한 뒤 공개 주소에서 같은 질문으로 재확인합니다.

공식 문서: [Vercel의 하위 폴더 배포](https://vercel.com/docs/monorepos), [Python api 폴더 방식](https://vercel.com/docs/functions/runtimes/python/api-directory), [Gemini API 키](https://ai.google.dev/gemini-api/docs/api-key).
