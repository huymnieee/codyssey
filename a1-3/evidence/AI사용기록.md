# AI 코딩 도구 사용 과정

이 문서는 2026-10-15 Codex에서 실제 진행한 대화와 작업을 요약한 기록입니다. 전체 대화를 그대로 내보낸 원본 로그는 아닙니다. 아래 인용은 실제 사용자 요청의 일부이며, 그 외는 작업 요약입니다. 수강생이 직접 작성하거나 직접 테스트했다고 꾸미지 않았습니다.

## 실제 요청 일부

> 학원과제이고 나는 ai 초보야
> 어려운 용어, 문장 쉽게 설명해주고 뭐하라는건지 쉽게 설명해줘
> 그리고 내가 해야될것 알려줘
> 크게 틀 잡아서 뭐뭐해야되는지 등

또한 사용자는 GitHub 코디세이 프로젝트에 a1-3 폴더를 만들어 올리고, 연결해서 만들 수 있는 부분을 최대한 준비해 달라고 요청했습니다.

## 요청을 구현으로 바꾼 과정

1. Codex가 과제 PDF 6쪽을 읽고 필수 제출물 5가지, 순수 HTML/CSS/JS, Python api 폴더, Vercel 공개 배포라는 조건을 추출했습니다.
2. 사용자에게 학습 도우미/요리 추천/다른 주제를 제안하고, 답변 전에는 학습 도우미 ‘공부한입’을 기본안으로 준비한다고 알렸습니다.
3. 연결된 GitHub에서 `huymnieee/codyssey`와 쓰기 권한을 확인했습니다.
4. 소개·AI 학습·사용 방법·도움말의 네 구역, 질문/설명 수준/결과/퀴즈/노트 다운로드 화면을 만들었습니다.
5. `fetch('/api/learn')`로 Python 백엔드를 호출하고, 서버 환경 변수의 Gemini 키로 실제 AI API를 요청하도록 구현했습니다.
6. 빈 입력·잘못된 형식·API 오류·지연에 대한 안내를 넣었습니다. 키를 공개 코드에서 제외하고 AI 응답은 글자로 표시하게 했습니다.
7. 기획서, 초보자 안내, 배포 가이드, 검증 기록을 작성했습니다. 실제 테스트 결과와 미완료 사항은 별도 검증 기록에 구분합니다.

## 공개 배포 후속 작업

사용자가 Vercel 로그인과 접근 승인을 완료하고 ‘등록하고 배포해줘’라고 요청했습니다. Codex가 기존 Gemini 키를 공개 코드와 분리해 Vercel의 비밀 환경 변수에 등록하고, GitHub의 `a1-3` 폴더를 `gongbu-hanip` 프로젝트로 배포했습니다. 공개 URL은 https://gongbu-hanip.vercel.app 이며 실제 AI 답변과 메뉴 이동, 화면 크기와 다운로드를 확인했습니다. 상세 증빙은 `검증기록.md`에 있습니다.

## 학습자가 확인할 부분

사용자는 추가로 API에 대해 실제로 질문하는 시연과 GitHub 업로드를 요청했습니다. Codex가 사용자 지정 공개 탭에서 174자 질문을 제출해 설명·비유·핵심 정리·퀴즈를 받았고 원문·다운로드 노트·화면 증빙을 저장했습니다. 이후 사용자는 PDF 완료 여부 재점검과 동료평가·발표·예상 질문을 한 번에 볼 노션용 자료를 요청했고, `docs/노션용_과제설명_동료평가.md`를 작성했습니다. 사용자의 이해나 학원 최종 제출을 대신 완료했다고 표시하지 않았습니다.
