# 이 과제, 쉽게 말하면

**AI가 답해 주는 작은 웹사이트를 만들고, 다른 사람도 접속할 수 있게 공개하는 과제예요.**

코드는 AI에게 도움받아도 돼요. 다만 내가 만든 사이트가 어떻게 움직이는지, 오류가 나면 무엇을 확인할지 설명할 수 있어야 해요. 과제 안내에 적힌 학습시간은 40시간이지만, 그 자체가 40시간짜리 영상을 제출하라는 뜻은 아니에요.

## 크게 다섯 가지예요

| 할 일 | 쉬운 설명 | 이 프로젝트에서 준비한 것 |
| --- | --- | --- |

| 2. 사이트 만들기 | 화면과 AI 연결 코드를 작성 | 소개·AI 학습·사용 방법·도움말, Python API |
| 3. 인터넷에 올리기 | 내 컴퓨터 밖에서도 열리는 주소 만들기 | GitHub의 a1-3 폴더 + Vercel 배포 설정 |

## 어려운 문장을 풀면

| 과제 문장 | 실제로 하라는 일 |

| 프론트와 백엔드 구조 구분 | 사용자가 보는 화면 코드와 AI 회사에 요청하는 서버 코드를 나눠 놓아요. |

| 환경 변수로 키 관리 | 비밀번호 같은 키를 공개 코드에 쓰지 않고, 서버 설정의 비밀 칸에 넣어요. |
| 로컬/배포 환경 | 로컬은 내 컴퓨터에서 연습하는 상태, 배포는 인터넷에 공개해 다른 사람도 쓰는 상태예요. |
| 커밋 이력 | GitHub에 어떤 코드를 언제 저장했는지 기록을 남겨요. |

| 증빙 자료 | 실제 화면과 AI에게 도움받은 과정을 파일로 보여줘요. |

## 꼭 필요한 것과 선택인 것

필수는 실제 AI 기능, 메뉴가 있는 3개 이상 구역, 모바일 대응, Python 백엔드, Vercel 공개 주소, GitHub 코드, 문서와 증빙이에요.

데이터 저장, 다른 서비스에 알림 보내기, 방문자 분석, 다크 모드는 **보너스**예요. 과제 완성을 위해 꼭 추가할 필요는 없어요. 도메인 구매나 회원가입 기능도 필수 조건이 아니에요.

## 내가 직접 해야 하는 최소한

1. **주제와 내용 확인:** ‘공부한입’을 내 과제로 써도 괜찮은지 보고, 내 질문 하나를 넣어 직접 써 보세요. 바꾸고 싶은 이름이나 문구는 Codex에게 말하면 돼요.
2. **Vercel 본인 로그인/연결:** 계정 인증이 필요할 때 직접 해 주세요. 현재 배포 상태는 README에 적혀 있어요.
3. **배포 서버에 키 설정:** 자동 연결로 처리되지 않으면 Vercel의 Environment Variables에 `GEMINI_API_KEY`와 `GEMINI_MODEL`을 넣어요. 키는 채팅이나 GitHub에 붙이지 마세요. 방법은 `배포가이드.md`에 있어요.
4. **직접 이해하기:** 아래 설명 6개를 소리 내서 말해 보세요. AI가 이해 여부를 대신 확인할 수는 없어요.
5. **학원 제출:** 공개 주소와 GitHub 폴더 주소를 학원에서 정한 제출 화면에 넣어요. 제출 방식과 마감은 이 PDF에 적혀 있지 않아요.

로그인과 계정 설정이 끝나면 Codex가 배포 확인·스크린샷·문서 갱신을 이어서 도와줄 수 있어요. 미완료 항목이 남았는데 제출 완료라고 쓰지 않도록 해요.

## 발표 전에 이 여섯 가지만 이해해요

**1. HTML, CSS, JavaScript가 뭔가요?**

“HTML은 제목·버튼 같은 화면의 뼈대, CSS는 색과 배치, JavaScript는 버튼을 눌렀을 때 동작을 담당합니다.”

**2. 내가 질문하면 어떻게 답이 나오나요?**

“JavaScript가 질문을 받아 `fetch`로 우리 서버에 보냅니다. Python 서버가 Gemini에 설명을 요청합니다. 답이 돌아오면 JavaScript가 화면에 보여줍니다.”

질문 입력 → JavaScript → `/api/learn` Python → Gemini → Python → JavaScript → 화면

**3. Serverless는 뭔가요?**

“서버 컴퓨터를 제가 직접 운영하지 않고, Vercel이 요청을 받을 때 Python 함수를 실행해 주는 방식입니다.”

**4. 키를 왜 환경 변수에 넣나요?**

“키는 AI 서비스를 쓰게 해주는 비밀번호 같은 값입니다. 화면 코드에 쓰면 다른 사람이 볼 수 있어서, 서버 설정에서만 읽게 했습니다.”

**5. 로컬과 배포는 뭐가 다른가요?**

“로컬 주소는 제 컴퓨터에서 연습할 때 쓰고, Vercel 주소는 다른 사람도 접속할 때 씁니다. 로컬 키와 Vercel 키는 각각 설정합니다.”

**6. 오류가 나면 어떻게 하나요?**

“먼저 질문이 비었는지 봅니다. 그다음 서버 키와 모델 설정, 인터넷 연결과 AI 이용 한도를 확인합니다. 코드를 고쳤으면 GitHub에 다시 저장하고 Vercel에서 새로 배포된 결과를 확인합니다.”

외우기만 하지 말고 ‘내가 질문을 적으면 코드 어디로 갈까?’를 파일에서 따라가 보면 좋아요. `js/app.js`의 `fetch`와 `api/learn.py`의 `generate_lesson`이 핵심이에요.
