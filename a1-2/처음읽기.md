# 오늘 과제, 이것부터 읽으세요

**이미 실행을 마치고 동료평가를 준비한다면 [동료평가 설명서](동료평가_설명.md)부터 읽으세요.** 실제로 저장된 경주 추천과 맛집 5곳 결과를 보면서 설명하는 순서, 약 1분 대본, 예상 질문을 정리했습니다. [필수 요구사항 확인표](평가체크리스트.md)도 있습니다.

## 가장 쉽게 시작하기 (Mac)

이 폴더의 **`여행추천_시작.command`를 더블클릭**하세요. 터미널에 메뉴가 열립니다.

- `1` → Enter: API 키 없이 연습 실행. 날짜도 Enter만 누르면 예제 날짜를 사용합니다.
- `2` → Enter: 실제 실행. 키가 저장되어 있지 않으면 먼저 키를 입력받고, 성공하면 제출 ZIP까지 만듭니다.
- `3` → Enter: API 키를 입력하거나 변경합니다. 키는 화면에 표시되지 않습니다.

시작 메뉴의 날짜는 `2026-11-01`과 `20261101` 모두 입력할 수 있습니다.

실행이 끝나면 결과 폴더가 열립니다. 연습 결과는 제출용 실제 실행 증빙이 아닙니다.
API 키 발급은 아래 2번 또는 `README.md`의 3번을 참고하세요.

## 과제를 한 문장으로

**날짜 하나를 입력하면 AI 추천과 맛집 검색을 거쳐 여행 안내문이 만들어지는 프로그램**을 제출하는 과제예요.

예를 들어 `2026-10-20`을 입력하면 다음처럼 동작해요.

1. AI에게 "이때 국내 어디로 여행 가면 좋을까?"라고 물어요.
2. AI가 추천한 도시 이름으로 카카오에서 맛집을 찾아요.
3. 추천 내용과 맛집을 AI에게 함께 보내 여행 안내문을 만들어요.
4. 컴퓨터에 데이터 파일 1개와 사람이 읽는 보고서 1개를 저장해요.

웹사이트, 휴대폰 앱, 지도 화면을 만들 필요는 없어요. **터미널에서 실행되는 프로그램이면 됩니다.**

## 제출물은 무엇인가요?

| 제출물 | 쉽게 설명하면 | 이 폴더에서 |
| --- | --- | --- |
| Python 프로그램 | 실제로 일을 하는 코드 | `travel_planner.py` |
| JSON 결과 | AI 추천과 맛집을 항목별로 저장한 데이터 | 실제 실행 후 `results/`의 `_raw.json` |
| Markdown 보고서 | 여행 추천 이유/날씨/행사/맛집/하루 일정이 적힌 글 | 실제 실행 후 `results/`의 `_travel_plan.md` |
| README | 실행 방법과 키 설정을 적은 사용 설명서 | `README.md` |

과제 PDF는 GitHub 링크로 낼지, ZIP을 올릴지까지 정하지 않았어요. **교육기관의 과제 제출 화면 안내가 기준**입니다. 별도 발표자료나 웹사이트 제작도 PDF의 필수 항목에는 없어요.

## 지금부터 할 순서

**1. 연습 실행으로 결과가 어떻게 생기는지 보기 (약 2~5분)**

터미널 앱을 열고 아래를 한 줄씩 실행하세요. 터미널은 Mac에서 Spotlight(Command+Space)에 '터미널'을 검색해 열 수 있어요.

```bash
cd /Users/hmhm/Downloads/a1-2
python3 travel_planner.py --date "2026-10-20" --demo
```

`examples/demo_results/`에 가상 데이터로 만든 연습 파일이 생겨요. **이것은 실제 API를 연결했다는 증빙이 아닙니다.**

**2. API 키 두 개 준비하기 (처음이면 약 15~40분, 계정 상태에 따라 더 걸릴 수 있음)**

- Google AI Studio에서 Gemini API 키 발급
- Kakao Developers에서 앱 생성 → 카카오맵 사용 설정 ON → REST API 키 확인

자세한 링크와 절차는 `README.md`의 3번에 있어요. 새 프로그램을 많이 연결할 필요는 없어요. 이 과제에는 AI 서비스와 장소 검색 서비스 두 개면 됩니다.

**3. 본인 컴퓨터에 키 저장하기 (약 3~5분)**

```bash
python3 setup_keys.py
```

키를 붙여 넣어도 화면에 보이지 않아요. 정상입니다. 첫 번째 키를 붙여 넣고 Enter, 두 번째 키를 붙여 넣고 Enter를 누르세요. 키를 채팅이나 GitHub에 올리지 마세요.

**4. 실제 실행하기 (약 1~5분, 서비스 상태에 따라 달라짐)**

```bash
python3 travel_planner.py -date "2026-10-20"
```

날짜는 원하는 날짜로 바꿔도 돼요. `results/`에 결과 파일 2개가 생겨요. 오류가 나면 설명서의 오류 표를 보거나, **키가 보이지 않는 오류 문구만** 알려주세요.

**5. 내용을 확인하고 제출 준비 (약 10~15분)**

- 보고서에 추천 지역, 이유, 날씨, 행사, 맛집, 오전/오후/저녁 일정이 있는지 확인
- 맛집이 0개여도 "데이터 없음"으로 나오고 보고서가 완성되면 과제에서 허용하는 경우예요.
- JSON에서 `mode`가 `live`, `status`가 `completed`, `report_source`가 `gemini`인지 확인
- `python3 package_submission.py`로 제출 ZIP 만들기
- 교육기관 제출 안내에 맞게 ZIP 업로드 또는 GitHub 링크 제출
- `.env`는 제출하지 않기

## 제가 이해하고 설명할 수 있어야 하는 핵심

아래 내용을 본인 말로 설명할 수 있으면 좋아요.

"날짜를 AI에 보내서 도시와 날씨, 행사 후보를 JSON으로 받습니다. JSON에서 도시 이름을 꺼내 카카오 맛집 검색에 사용합니다. 그 추천과 맛집 목록을 다시 AI에 보내 최종 보고서를 만듭니다."

"카카오 맛집 검색에 실패하면 오류를 기록하고 맛집을 데이터 없음으로 표시해 보고서를 계속 만듭니다. AI가 잘못된 JSON을 보내면 한 번만 다시 요청합니다."

"API 키는 서비스 인증값이므로 코드에 넣지 않고 .env에 따로 보관합니다. GitHub와 제출 파일에는 포함하지 않습니다."

## 시간은 얼마나 잡으면 되나요?

PDF의 **40시간은 전체 학습 시간 안내**예요. 이 폴더의 코드가 준비된 상태에서 계정과 키 발급이 잘되면 **설정부터 결과 확인과 제출 준비까지 약 30~70분**을 예상할 수 있어요. 인증/권한 문제가 생기면 1~2시간 이상 걸릴 수 있습니다. 이는 보장 시간이 아닌 예상이에요.

오늘 다른 과제도 있다면 선택 보너스보다 **필수 기능 실제 실행 → 결과 확인 → 제출**을 먼저 끝내는 순서가 좋아요.

제가 코드 작성, 설명서 작성, 오류 수정, 결과 확인과 ZIP 준비를 도울 수 있어요. 본인 로그인/인증, API 키 발급, 과제 제출 사이트에서 최종 제출 확인은 직접 해야 하는 단계가 남아 있어요.
