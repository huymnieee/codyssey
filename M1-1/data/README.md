이 프로젝트는 삼성전자·SK하이닉스 주가를 코스피 지수와 비교한다.

| 대상 | 코드 | 분석 기간 | 분석용 관측 수 | 계산 준비용 관측 수 | 파일 |
|---|---|---|---:|---:|---|
| 삼성전자 보통주 | 005930 | 2023-01-02 ~ 2026-09-30 | 913 | 125 | `raw/samsung_daily.csv` |

표의 파일은 수집 명령을 실행한 뒤 생성된다. 공개 저장소에는 원본 응답과 전체 일별 가격 시계열을 포함하지 않는다. 처음 실행할 때에는 README의 `src/reproduce.py --collect` 절차를 사용한다. 기존 로컬 보관본은 유지한다.

- 원본 응답 수집일: 2026-10-26, 한국 시간. 정확한 시각은 `manifest.json` 참조.
- 요청한 분석 기간: 2023-01-01 ~ 2026-09-30. 실제 첫 거래일은 2023-01-02다.
- 분석용 관측 수는 각 시계열 913개이며, 3개를 합쳐 2,739개다. 같은 날짜는 913개다.
- 각 CSV에는 2022-07-01 ~ 2022-12-29의 준비 구간 125거래일도 포함되어 총 1,038행이다.
- 준비 구간은 이동평균과 첫 달 수익률 계산에만 활용하며, 분석 기간의 성과 통계에 섞지 않는다.
- 수집된 세 시계열의 분석 날짜 집합은 같다. 이후 독립 거래일 달력의 휴장 예외를 확인해 반영했고 날짜 집합 일치를 확인했다. 자세한 근거는 정제 기록에 있다.
- 연도별 분석 관측 수: 2023년 245개, 2024년 244개, 2025년 242개, 2026년 1~9월 182개.

## 출처와 수집 방식

제공처는 네이버 금융의 일별 차트 데이터다. 코스피는 제공되는 지수 값을 사용하며, 종목 시가총액으로 직접 재계산하지 않는다.

- [삼성전자 원본 응답 주소](https://fchart.stock.naver.com/sise.nhn?timeframe=day&count=1600&requestType=0&symbol=005930)
- [SK하이닉스 원본 응답 주소](https://fchart.stock.naver.com/sise.nhn?timeframe=day&count=1600&requestType=0&symbol=000660)
- [코스피 원본 응답 주소](https://fchart.stock.naver.com/sise.nhn?timeframe=day&count=1600&requestType=0&symbol=KOSPI)
- 수집 인터페이스 참고: [FinanceDataReader의 네이버 수집 코드](https://github.com/FinanceData/FinanceDataReader/blob/master/src/FinanceDataReader/naver/data.py).

`source/`에는 제공처의 XML 응답을 바이트 그대로 보관했다. XML 응답은 수집 당시 최근 1,600개 관측을 담으므로 분석 기간 밖의 날짜도 포함한다. 분석에서는 고정한 기간만 선택한다. CSV는 응답에서 2022-07-01 ~ 2026-09-30을 선택해 날짜순으로 저장한 자료다. 출처 값을 보간하거나 급변일을 삭제하지 않았다.

`manifest.json`에는 출처 주소, 수집 시각, 기간, 행 수, 원본·CSV의 SHA-256 해시를 기록했다. 해시는 나중에 파일 내용이 달라졌는지 확인하는 값이다.

## 컬럼과 가격 기준

| 컬럼 | 의미 | 단위·기준 |
|---|---|---|
| Date | 거래일 | 한국 시장 날짜, YYYY-MM-DD |
| Open | 시가 | 기업 주가는 원, 코스피는 포인트 |
| High | 고가 | 기업 주가는 원, 코스피는 포인트 |
| Low | 저가 | 기업 주가는 원, 코스피는 포인트 |
| Close | 종가 | 기업 주가는 원, 코스피는 포인트 |
| Volume | 제공처의 거래량 값 | 원값 보관. 코스피 거래량 단위는 미확인으로 분석에서 제외 |

- 주 분석에는 `Date`와 `Close`를 사용한다.
- 가격은 네이버 응답의 값을 그대로 사용하며 이 스크립트에서 추가 수정하지 않았다.
- 응답 자체에는 수정주가 적용 기준이 표시되어 있지 않다. 이후 두 기업은 KRX 원천 종가를 분석 기준으로 선택했다. 추가 대조의 확인 범위와 남은 한계는 정제 기록에 있다.
- 배당·분배금 자료를 수집하거나 배당 재투자를 계산하지 않았다. 최종 보고서에서 배당 포함 총수익률로 표현하지 않는다.
- CSV 인코딩은 UTF-8 BOM이며, 별도 외부 라이브러리 없이 Python 표준 라이브러리로 생성한다.

## 다시 실행하기

프로젝트 최상위 폴더에서 Python 3.10 이상으로 실행한다.

```bash
python3 src/fetch_data.py
```

기존 XML 응답과 수집 기록이 있으면 인터넷 재조회 없이 같은 CSV를 재생성한다. 준비·분석 기간과 응답 날짜를 확인하고 최소 100개 조건을 검사한다.

원본을 새로 수집하려면 다음 명령을 사용한다. 이 명령은 보관된 응답과 수집 기록을 교체한다. 제공처의 과거 값 수정이나 최신 1,600개 조회 범위 이동으로 결과가 달라질 수 있다.

```bash
python3 src/fetch_data.py --refresh
```

## 이용 조건과 다음 점검

자료를 학습 분석에 활용한다. 공개 응답에 접근할 수 있다는 사실만으로 데이터의 재배포 라이선스가 주어지는 것은 아니다. 데이터 자체를 GitHub에 공개할 때에는 원 제공처의 이용 조건을 확인하고, 공개 가능한 범위가 불명확하면 원본 대신 수집 코드와 방법을 제공한다.

이 문서의 표는 처음 수집한 NAVER 원본에 관한 기록이다. 이후 기본 검사와 출처·달력 대조를 완료했다. 두 기업의 종가 20건이 KRX 원천 보관본과 달라 최종 분석은 두 기업 모두 KRX 기준으로 통일했다. 원본 CSV는 바꾸지 않았다. 최종 분석 자료는 `processed/`에 있다.

자세한 근거와 가격 기준의 한계는 [정제 기록](../results/data_preparation.md), 기본 검사 결과는 [검사 기록](../results/data_quality.md)을 참조한다. 휴장 공지로 확인한 날짜는 결측으로 채우지 않았다.
