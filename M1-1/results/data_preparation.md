# 분석용 데이터 정제 기록

## 선택한 기준

- 삼성전자·SK하이닉스: 한국거래소(KRX) 원천 시세를 보관한 FinanceData/marcap의 종가.
- 코스피: NAVER가 제공하는 코스피 지수 종가. 직접 재계산하지 않았다.
- 배당 재투자는 계산하지 않으며, 결과는 배당 포함 총수익률이 아닌 가격 변화다.
- 준비 구간 2022-07-01~2022-12-29 125거래일, 분석 구간 2023-01-02~2026-09-30 913거래일.

## 기본 검사를 통과한 뒤 발견한 차이

빈칸·중복·숫자 형식·가격 범위 검사에서는 세 원본 모두 문제가 없었다. 하지만 가격 제공처를 대조하니 일부 종가가 달랐다.

1. NAVER와 Yahoo의 종가를 비교했다. 삼성전자 24일, SK하이닉스 21일이 달랐다. Yahoo에는 두 기업 모두 2025-09-19가 없었다. 따라서 Yahoo 자료로 일괄 교체하거나 누락 날짜를 보간하지 않았다.
2. KRX 원천 시세의 보관본을 별도로 확보했다. 저장소 커밋 `9d890e304238340a9d40a08e680e276c8d80ceab`로 고정하고, 2022~2026년 연도별 파일의 Git blob SHA와 SHA-256을 기록했다.
3. 두 기업 각각 1,038일을 KRX 원천 보관본과 대조했다. 날짜는 전부 같았고 종가는 삼성전자 9건, SK하이닉스 11건이 달랐다. 이 20건은 모두 2026년 9월에 있다. 제공처 간 차이의 발생 원인을 확정하지는 않았다.
4. 분석 기준을 두 기업 모두 KRX 원천 종가로 통일했다. KRX와 NAVER가 같았던 날은 값이 그대로이며, 달랐던 20건만 분석용 값이 바뀐다.

| 2026-09-30 | 원본 NAVER 종가 | 분석에 사용한 KRX 원천 종가 |
|---|---:|---:|
| 삼성전자 | 269,500원 | 268,500원 |
| SK하이닉스 | 1,783,000원 | 1,776,000원 |

사용자가 원본 파일에서 찾아낸 값은 해당 파일의 값을 올바르게 읽은 결과다. 분석 기준을 정제하면서 마지막 가격과 수익률이 달라졌다. 최종 보고서는 정제 후 값으로 작성한다.

NAVER 원본 CSV와 XML은 그대로 보관한다. 수정된 날짜·전후 가격은 `source_differences.csv`, 전체 대조와 근거 해시는 `krx_comparison.json`에 있다.

## 거래일 확인

exchange_calendars 4.13.2의 XKRX 달력을 별도로 생성해 대조했다. 라이브러리가 거래일로 표시하던 2026-06-03·2026-07-17은 시장 운영 공지와 증권사 일정에서 휴장임을 확인했다. 이 두 예외를 반영하면 준비·분석 구간 1,038일과 세 자료의 날짜 집합이 정확히 일치한다.

- 2026-06-03 지방선거 휴장: [KRX 시장 운영 공지 목록](https://strn.krx.co.kr/corebbs5/BHPSTRN0401/list), [키움증권 2026년 6월 캘린더](https://invest.kiwoom.com/inv/calendar?date=20260628).
- 2026-07-17 제헌절 휴장: [KRX 시장 운영 공지 목록](https://strn.krx.co.kr/corebbs5/BHPSTRN0401/list), [미래에셋증권 2026년 7월 일정](https://securities.miraeasset.com/bbs/board/message/view.do?categoryId=1539&messageId=2340801).

휴장일은 결측 오류로 간주하거나 가격을 채우지 않았다. 다른 거래일 누락과 추가 날짜는 발견하지 못했다.

## 가격 기준의 확인 범위

- KRX 원천 종가를 기준으로 통일해 기간 내 가격 비교 기준을 맞췄다.
- Yahoo가 제공하는 준비·분석 구간의 주식 분할 이벤트는 없었다.
- NAVER 응답의 수정주가 정책 전체를 확정한 것은 아니다. 분석에는 추가 가격 조정을 하지 않았고, 배당·분배금을 재투자하지 않았다.
- 코스피는 1,038일의 NAVER 종가와 Yahoo 종가가 0.02포인트 허용 오차 안에서 모두 일치했다.
- 기본 검사와 제공처 대조는 오류 가능성을 낮추는 확인이며, 모든 제공처의 상류 데이터가 완전히 독립적이라는 의미는 아니다.

## 저장된 분석 자료

- `data/processed/close_prices.csv`: 계산 준비 구간을 포함한 1,038행, Date·samsung·sk_hynix·kospi.
- `data/processed/analysis_prices.csv`: 실제 분석 구간 913행. 기업 가격은 원, 코스피는 포인트.
- 원본은 `data/raw/`, 대조 스냅샷과 선택한 KRX 종가는 `data/reference/`에 있다.

## 재현

```bash
.venv/bin/python src/verify_sources.py
.venv/bin/python src/compare_krx.py
.venv/bin/python src/analyze.py
```

`analyze.py`는 보관한 두 기업의 선택 종가와 코스피 원본으로 인터넷 없이 같은 분석용 자료를 만든다. `compare_krx.py`로 연도별 원본을 다시 대조할 때에는 `.cache/`가 없으면 고정한 커밋의 파일 약 118MB를 다운로드한다. Yahoo 대조는 보관한 JSON 응답을 재사용한다.

KRX 원천 데이터 설명: [FinanceData/marcap](https://github.com/FinanceData/marcap). 원본 재배포에 관한 이용 조건은 별도 확인 대상이며, 이 자료가 공개되어 있다는 사실만으로 자유 재배포 라이선스가 부여되는 것은 아니다.
