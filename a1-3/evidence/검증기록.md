## 공개 환경에서 확인한 것

| 점검 | 결과와 증빙 |
| --- | --- |
| 로그인 없는 공개 접속 | 인증 쿠키 없는 Python HTTP 요청과 별도 브라우저에서 사이트 접속. `/` HTTP 200 |
| CSS와 JavaScript | 각각 HTTP 200, 올바른 Content-Type, nosniff 헤더 확인 |
| 네 메뉴 | 소개 `#home`, AI 학습 `#learn`, 사용 방법 `#guide`, 도움말 `#faq`의 실제 이동 URL 확인 |
| 실제 AI 일반 질문 | 공개 브라우저에서 API 예제 → Python 서버 → Gemini → 요약/설명/비유/3가지 핵심/퀴즈 표시 확인 |
| 긴 질문 | 300자 질문으로 HTTP 200, `mode=live`, `source=gemini`. `deployed-api-result.json` 저장 |
| 빈 질문 | POST 요청에서 HTTP 400과 ‘2~500자로 적어 주세요’ 안내. `deployed-http-checks.json` 저장 |
| 잘못된 HTTP 메서드 | GET `/api/learn`에서 HTTP 405 |
| 비밀 파일 | `/.env` 요청에서 HTTP 404 |
| 반응형 | 데스크톱 1440×1000, 모바일 390×844 설정에서 확인. 모바일 가로 넘침 없음 |
| 퀴즈 | 실제 AI 질문의 정답과 해설 펼치기 확인 |
| 다운로드 | 공개 Chrome에서 TXT 다운로드 후 파일의 실제 AI 결과 제목과 퀴즈 포함 확인. `downloaded-study-note.txt` 보관 |
| 브라우저 로그 | 공개 Chrome의 warning/error 로그 0건. Vercel 최근 30분 Runtime Logs에서 Info 5, Warning 0, Error 0, Fatal 0 확인. 정상 질문 3회는 HTTP 200, 의도한 빈 질문 400과 GET 405 기록 |

자동 테스트는 로컬에서 8개 통과했습니다. 입력 길이/설명 수준/키 누락/401·403·429·500/시간 초과/네트워크/응답 형식/비밀 값 제거를 모의 응답으로 검증했습니다. JavaScript 문법 검사도 통과했습니다. 이 자동 테스트와 실제 공개 API 호출은 서로 다른 검증입니다.
