# 노코드 자동화 기초: 워크플로우 설계

반복 업무를 분석하고 Make와 n8n으로 실제 자동화 워크플로우를 구현한 과제입니다.

## 프로젝트 구성

### [프로젝트 1: 자동화 도구 비교 구현](project1-tool-comparison/README.md)

- 주제: 학생 성적 판정 자동화
- 비교 도구: Make, n8n
- Trigger: Google Sheets 새 행 감지
- 조건 분기: 합격 / 불합격 / 확인필요
- Action: 결과별 Google Sheets 저장, Discord 알림
- 포함 자료: 도구별 구현 화면, 실행 결과, 비교 분석

### [프로젝트 2: 자유 주제 자동화](project2-free-automation/README.md)

- 주제: 재수학원 문의 긴급/일반 자동 분류
- 사용 도구: Make
- Trigger: Google Sheets 새 문의 감지
- 조건 분기: 긴급 / 일반
- Action: Discord 알림, Google Sheets 처리 결과 기록
- 포함 자료: 워크플로우 설계, 구현 화면, 두 분기 실행 결과

## 핵심 개념

- **Trigger:** 자동화를 시작시키는 사건 또는 조건
- **Action:** Trigger 이후 자동으로 실행되는 작업
- **Filter/Router:** 조건에 따라 데이터를 통과시키거나 여러 경로로 나누는 기능

## 보안 안내

- 문서와 캡처에 등장하는 이름, 점수, 연락처는 실습을 위해 만든 가상 테스트 데이터입니다.
