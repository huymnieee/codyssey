API란 무엇일까요

[한 줄 요약]
API는 서로 다른 소프트웨어가 서로 대화를 나누고 데이터를 주고받게 도와주는 연결 통로입니다.

[쉬운 설명]
컴퓨터 프로그램끼리 일을 시키거나 정보를 전달할 때 사용하는 규칙입니다. 공부한입의 과정은 사용자가 질문을 입력하면 자바스크립트가 서버에 정보를 요청하고 서버는 다시 인공지능에게 물어본 뒤 결과를 화면에 보여주는 흐름입니다. 즉 API는 내가 직접 인공지능을 만들지 않아도 인공지능의 능력을 빌려 쓸 수 있게 해주는 중개인입니다. 자바스크립트의 fetch는 인공지능에게 질문을 전달하는 배달원 역할을 합니다. API 키는 나만 알고 있어야 하는 일종의 비밀번호입니다.

[일상 속 비유]
식당에서 손님인 내가 점원에게 메뉴를 주문하고 주방에서 요리를 만들어 내오는 과정과 같습니다. 여기서 손님은 나이고 주방은 인공지능 서버이며, 내 주문을 주방에 전달하는 점원이 바로 API입니다.

[기억할 것]
- API는 서로 다른 프로그램이 대화할 수 있게 해주는 약속입니다.
- 내가 직접 어려운 인공지능 기능을 개발하지 않아도 API를 통해 쉽게 가져다 쓸 수 있습니다.
- API 키는 내 돈이 빠져나갈 수 있는 비밀번호와 같아서 반드시 안전하게 관리해야 합니다.

[확인 퀴즈]
식당 비유에서 손님의 주문을 주방에 전달하는 API의 역할은 무엇인가요?

[정답과 해설]
정답은 점원입니다. 점원은 손님의 요구사항을 주방에 전달하고 완성된 요리를 가져다주는 중개 역할을 하기 때문입니다.
