# 공부한입 서비스 기획서

## 1. 목적과 사용자

- 서비스명: 공부한입
- 목적: 낯선 용어 앞에서 공부를 포기하는 초보자가 한 가지 개념부터 이해하고 스스로 확인하도록 돕는다.
- 타겟 사용자: 프로그래밍과 AI를 처음 배우는 학원 수강생, 어려운 문장을 쉽게 풀어보고 싶은 학습자.
- 해결할 문제: 검색 결과도 어려운 말이 많고, 설명을 읽어도 이해했는지 확인하기 어렵다.
- 제공 가치: 쉬운 설명 → 일상 속 비유 → 핵심 3가지 → 퀴즈를 한 번에 제공한다.
- 과제 예시와의 차이: 반려동물 추천 예시를 복제하지 않고 학습 도우미라는 주제, 질문 중심 구성, 종이 노트와 녹색 계열 디자인, 학습 노트 다운로드를 설계했다.

## 2. 메뉴와 구역

| 메뉴 | 주소 | 내용 |
| --- | --- | --- |
| 소개 | `#home` | 서비스 목적과 시작 버튼 |
| AI 학습 | `#learn` | 질문, 설명 수준, 결과, 퀴즈, 노트 다운로드 |
| 사용 방법 | `#guide` | 질문하기·이해하기·퀴즈 확인하기 |
| 도움말 | `#faq` | 질문 범위, 오류, 입력 전송, 정확도 안내 |

상단 메뉴를 누르면 한 페이지 안에서 해당 구역으로 이동한다. 720px 이하에서는 입력과 결과를 한 칸으로 쌓는다. 1000px 이하에서도 여백과 글자 크기를 조정한다.

## 3. 핵심 AI 기능

입력은 주제 또는 어려운 문장(앞뒤 공백 제외 2~500자)과 설명 수준(처음/기초/복습)이다. 출력은 제목, 한 줄 요약, 쉬운 설명, 일상 속 비유, 핵심 3가지, 퀴즈 질문과 정답이다. 정답은 펼치기 전까지 가려 둔다.

프론트는 `fetch('/api/learn')`로 JSON을 전송한다. Vercel의 Python 함수가 서버 환경 변수에서 키를 읽어 Gemini REST API를 호출한다. 구조화된 JSON 응답을 검증한 뒤 화면에 전달한다. AI 출력은 `textContent`로 넣어 HTML로 실행되지 않게 한다. 결과는 사용자가 원할 때 TXT 파일로 저장한다. 데이터베이스는 사용하지 않는다.

## 4. 실패 처리 기준

| 상황 | 처리 |
| --- | --- |
| 빈 입력/1자/500자 초과 | 브라우저와 서버에서 거절, 2~500자로 입력 안내 |
| 잘못된 설명 수준/JSON | 400 응답, 다시 선택/입력 안내 |
| 요청 본문 8KB 초과 | 413 응답 |
| 서버 키 미설정 | 503 응답, 운영자 설정 안내 |
| 제공자 인증 실패(401/403) | 503 응답, 키 설정 확인 안내. 오류 원문·키 비공개 |
| 제공자 요청 한도(429) | 429 응답, 잠시 뒤 재시도 안내 |
| 제공자 오류/네트워크 | 502 응답, 연결/재시도 안내 |
| AI 응답 형식 오류/빈 결과 | 502 응답, 질문 변경 또는 재시도 안내 |
| 지연 | 12초 후 기다림 안내, 서버 요청 35초 제한, 브라우저 48초 후 중단 |
| 연속 클릭 | 요청 중 버튼 잠금. 자동 재시도 없음 |

요청 중 이전 결과를 잠시 숨기며, 실패하면 이전 학습 노트라고 표시해 복원한다. 새 답변으로 오해하지 않도록 한다.

## 5. 보안과 운영

- 키는 `.env` 또는 Vercel 환경 변수에서 읽는다. `.env`는 GitHub/배포 업로드 대상에서 제외한다.
- 입력과 결과는 서비스 데이터베이스에 저장하지 않는다. 질문은 Gemini에 전달되므로 개인정보를 적지 않도록 화면에 안내한다. 제공자의 정책은 별도로 적용된다.
- 입력 길이와 출력 토큰 수를 제한한다. 자동 재시도와 무한 호출을 하지 않는다.
- 공개 API에는 사용자별 인증/서버 전체 호출 횟수 제한이 아직 없다. 버튼 잠금은 한 브라우저의 중복 클릭만 줄인다. 다수 사용자 운영 시 Vercel 방화벽/호출 제한과 제공자 사용량 제한을 추가한다. 현재는 학원 과제 시연 범위다.
- 이 서비스의 답변은 학습 보조용이며 오류 가능성이 있어 교재와 비교하도록 안내한다.

## 6. 완료 판정

공개된 Vercel 주소에서 메뉴 이동, 데스크톱·모바일 표시, 질문 입력부터 실제 AI 답변까지 확인되어야 최종 완료다. 로컬 테스트만으로 공개 배포 완료라고 판정하지 않는다. 검증 상태와 증빙은 `evidence/검증기록.md`에 기록한다.
