# GenAI 기초 1: LLM 기반 업무 자동화

다이어트 앱 사용자의 고민에 공감하고 안전한 행동 대안을 제시하는 AI 멘탈 코칭 답변 자동화 프로젝트입니다.

## 프로젝트 주제

* 과업명: 다이어트 앱 사용자를 위한 멘탈 코칭 답변 자동화
* 목표: 사용자의 상황과 감정을 이해하고 안전한 건강 정보와 실천 가능한 행동 대안을 제공
* 비교 모델: Gemini 3.1 Pro, Claude Fable 5, GPT-5.5
* 최종 선정 모델: Gemini 3.1 Pro

## 제출 문서

### 1. LLM 모델 비교·선정 보고서

동일한 프롬프트를 3개 LLM에 입력하고 공감 및 친절도, 정확성, 실천 가능성, 가독성을 기준으로 결과를 비교한 문서입니다.

### 2. 시스템 설계 문서

타겟 사용자, 입력 템플릿, 페르소나, 시스템 프롬프트, Few-shot 예시, v1과 v2 개선 과정, 환각 검증 내용을 정리한 문서입니다.

### 3. 실행 로그

선정한 업무 시나리오로 진행한 10턴 이상의 사용자와 AI 대화 기록입니다. 대화 중 추가 정보와 조건 변경이 반영되는 과정을 확인할 수 있습니다.

## 주요 학습 내용

* LLM별 답변 결과 비교
* 페르소나와 시스템 프롬프트 설계
* Few-shot 예시 작성
* 단계적 접근을 적용한 프롬프트 개선
* 환각 검증
* 긴 대화에서의 문맥 유지 확인
