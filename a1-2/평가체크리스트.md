## 검증 범위

- 자동 점검 **16개**: 정상 흐름, 날짜 검증, 키 누락, JSON 재시도 한도, 장소 API 실패/0건, 좌표 변환, HTTP 오류, 보고서 실패, 데모 구분, 저장 시 키 제거, 보고서 섹션/식당 정보 누락 검사

## 한계와 선택 범위

- 복수 도시 추천과 캐싱은 선택 보너스이며 미구현입니다.
- 날씨는 계절 설명이고 행사는 AI가 생성한 후보입니다. 실제 예보/개최 일정 검증 기능은 없습니다. 후보에 관광 활동이 섞일 수 있습니다.
- 보고서에서 필수 섹션과 제공된 식당 정보 누락은 검사하지만 모든 문장의 사실성을 자동 검증하지는 않습니다.
- 최종 AI 생성 실패 시 임시 보고서는 미완료로 표시하며 제출 ZIP에서 제외합니다.
- API 키·사용 권한·인터넷이 달라지면 재실행 결과와 성공 여부도 달라질 수 있습니다.
- 코드 구현과 문서 작성/점검에는 AI 도구의 도움을 받았습니다. 설명 자료는 실제 코드와 결과를 바탕으로 작성했습니다.
